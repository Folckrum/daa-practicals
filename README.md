# DAA Practicals (LP-III, BE Sem VII)

Clone the repo and run any file with Python. Every program asks for its input in the terminal.

| File | Practical | What you enter | Run |
|---|---|---|---|
| fibonacci.py | Fibonacci using recursion and loop, with complexity | n | `python fibonacci.py` |
| knapsack.py | Fractional knapsack (greedy) | items (weight, value) and capacity | `python knapsack.py` |
| huffman.py | Huffman encoding (greedy) | any text | `python huffman.py` |
| n_queens.py | n-Queens with the first queen placed (backtracking) | n and column of first queen | `python n_queens.py` |
| quick_sort.py | Quick sort, deterministic vs randomized | numbers separated by spaces | `python quick_sort.py` |

No extra libraries needed.
