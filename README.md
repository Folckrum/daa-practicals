# DAA Practicals (LP-III, BE Sem VII)

Clone, `cd` into the practical folder, run the script.

| Folder | Practical | Run |
|---|---|---|
| 01_fibonacci | Recursive and non-recursive Fibonacci, complexity | `python fibonacci.py` |
| 02_fractional_knapsack | Fractional knapsack (greedy) | `python knapsack.py` |
| 03_huffman_encoding | Huffman encoding (greedy) | `python huffman.py` |
| 04_n_queens | n-Queens with first queen placed (backtracking) | `python n_queens.py` |
| 05_quick_sort | Quick sort, deterministic vs randomized | `python quick_sort.py` |

No extra libraries needed.
